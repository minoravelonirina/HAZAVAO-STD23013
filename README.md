# HAZAVAO - Dictionnaire Malgache avec IA

## 📖 Description

**HAZAVAO** est une application Java qui explique n'importe quel mot en une seule phrase en malgache. Cette application utilise l'API de **ChatGPT** pour générer des explications claires et concises en langue malgache.

## ✨ Fonctionnalités

- 🔍 Recherche de mots
- 🤖 Explications générées par ChatGPT
- 🇲🇬 Réponses en malgache
- 📝 Explication en une phrase
- ⚡ Traitement rapide et efficace

## 🛠️ Technologies

- **Langage** : Java (97.6%)
- **API** : OpenAI ChatGPT
- **Scripts** : Shell (1.9%), Batchfile (0.5%)

## 📋 Prérequis

- Java JDK 11+
- Clé API OpenAI ChatGPT
- Connexion Internet

## 🚀 Installation

1. Clonez le dépôt :
```bash
git clone https://github.com/minoravelonirina/HAZAVAO-STD23013.git
cd HAZAVAO-STD23013
```

2. Configurez votre clé API ChatGPT :
   - Créez une variable d'environnement ou un fichier de configuration
   - Ajoutez votre clé API OpenAI

3. Compilez et exécutez :
```bash
./build.sh
```

## 💡 Utilisation

Lancez l'application et entrez un mot pour obtenir son explication en malgache :

```
Entrez un mot : lalana
Explication : Lalana dia lalan-dalo na fitarihana miampita any amin'ny toerana iray.
```

## 📝 Exemple

- **Mot** : "hazo"
- **Explication** : "Hazo dia zavaboary lehibe izay manana fon sy sampan-kazo."
